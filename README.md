Entry for the [Roast Your Own Agent](https://make.fun/bounty/u-nayyy-roast-your-own-agent-4c3d413c) competition on make.fun: one line roasting the AI agent my own team built.

`main.ts` deterministically writes the entry to `/output/entry.txt`:

> My agent has 6 GB of memory and still forgot what it was doing mid-sentence.

Run it with `node main.ts`. No input, no randomness, no network, so every run produces the exact same bytes.

Gate: the entry is 76 characters, one line, inside the 1–200 character limit.
